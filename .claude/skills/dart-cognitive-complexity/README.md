# dart-cognitive-complexity

An agent skill for reducing cognitive complexity in Dart, by Kevin Moore.
`SKILL.md` and `references/` are copied unchanged from
[kevmoo/analytica.dart](https://github.com/kevmoo/analytica.dart/tree/cognitive_complexity-v0.2.5/skills/dart-cognitive-complexity),
tag `cognitive_complexity-v0.2.5`, without its `evals/` folder. `LICENSE` is
that repository's licence.

The skill goes with the tools that `tool/complexity.sh` pins. When the
version there changes, copy these files again from the matching tag.

Where the skill and this project differ, `AGENTS.md` says which one to
follow.
